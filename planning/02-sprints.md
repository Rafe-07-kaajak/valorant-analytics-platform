# Sprint Planning

## Purpose

This document divides the roadmap into executable development sprints.

Each sprint should produce a working improvement to the platform.

No sprint should begin before the previous sprint satisfies its Definition of Done.

---

# Sprint 01 — Foundation

## Goal

### Deliverables

- Project cleanup
- Folder verification
- Design token system
- Theme system
- Typography
- Global layout
- Navigation
- Shared UI library
- Responsive framework

### Definition of Done

- Design system works
- Shared components reusable
- No placeholder UI

# Sprint Rules

Every sprint must:

- Start from an approved task.
- Follow CLAUDE.md.
- Respect documentation inside `/docs`.
- Pass its Definition of Done.
- Leave the repository in a working state.

No sprint may skip unfinished work from previous sprints.
