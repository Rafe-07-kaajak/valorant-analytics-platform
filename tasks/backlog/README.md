# Backlog

The backlog contains ideas, improvements, bugs, and future work that have not yet been scheduled into a sprint.

## Purpose

Items in the backlog are NOT implementation tasks.

A backlog item becomes a task only after:

- the scope is clearly defined
- priorities are agreed
- dependencies are understood
- it is assigned to a sprint

## Possible Backlog Items

Examples:

- New animation ideas
- Dashboard improvements
- UX enhancements
- Performance optimizations
- AI integrations
- Refactoring opportunities

## Workflow

Idea

↓

Backlog

↓

Sprint Planning

↓
